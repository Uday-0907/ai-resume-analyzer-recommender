# AI Resume Analyzer & Job Recommendation System

An NLP-powered Streamlit application that parses a resume, extracts technical
skills, scores compatibility against multiple job roles using **TF-IDF cosine
similarity** and **skill overlap**, highlights skill gaps, and generates a
personalised **4-week learning roadmap**.

---

## Features

| Feature | Detail |
|---------|--------|
| 📄 Resume Upload | PDF & DOCX, max 5 MB, in-memory only (never stored) |
| 🧹 Text Cleaning | Lowercases, strips symbols — preserves `C++`, `C#`, `.NET` |
| 🧠 Skill Extraction | 57 skills across 12 categories from `skill_dictionary.csv` |
| ⚖️ Job Matching | TF-IDF + skill-overlap blended score (70 / 30 weighting) |
| 🏆 Top 3 Roles | Ranked metric cards with gold / silver / bronze medals |
| 📊 Gauge Chart | Visual match-score indicator (0 – 100 %) |
| 🔍 Skill-Gap Analysis | Found vs. missing skills for the selected target role |
| 🗺️ 4-Week Roadmap | Structured week-by-week plan with resources + project ideas |
| 📥 Report Export | Full analysis as a downloadable `.txt` file |
| 🔒 Responsible AI | Prominent disclaimer — no personal demographics ever scored |
| 🤖 AI Feedback | Optional Gemini Flash feedback (requires `GEMINI_API_KEY`) |

## Setup & Installation

### Prerequisites
- Python 3.10 or newer
- `pip` package manager

### 1 — Clone the repository
```bash
git clone <your-repo-url>
cd resume_ai
```

### 2 — Create and activate a virtual environment
```bash
# Create
python -m venv venv

# Activate — Windows
venv\Scripts\activate

# Activate — macOS / Linux
source venv/bin/activate
```

### 3 — Install dependencies
```bash
pip install -r requirements.txt
```

### 4 — (Optional) Generate sample DOCX resumes
```bash
python scripts/create_sample_resumes.py
```
This creates three PII-free DOCX test resumes in `sample_resumes/`.

### 5 — Run the application
```bash
streamlit run app.py
```
Open the URL Streamlit prints (usually `http://localhost:8501`).

### 6 — Upload a resume and analyse
- Upload one of the sample resumes from `sample_resumes/`
- Choose a target role from the sidebar dropdown
- Review your match score, Top 3 roles, skill gaps, and 4-week roadmap
- Click **"📥 Download Analysis Report"** to export the full analysis

## How the Match Score Works

For each job role the score is computed as:

```
match_score = 0.70 × skill_overlap_ratio + 0.30 × tfidf_cosine_similarity
```

| Signal | Description |
|--------|-------------|
| `skill_overlap_ratio` | (matched skills ∩ role required skills) ÷ (role required skills) |
| `tfidf_cosine_similarity` | Cosine similarity between the TF-IDF vectors of the resume text and the role description |

Skill overlap is weighted more heavily because it is directly explainable
("you're missing Docker and MLflow"), while TF-IDF adds broader contextual
signal from how the resume is written.

## Optional Feature: AI-Generated Feedback

Uses **Gemini Flash** (Google AI Studio) via a controlled prompt — only
skill-level data is sent, never the raw resume text or any personal information.

**To enable:**
1. Get a free API key: https://aistudio.google.com/apikey
2. Open `.env` and set `GEMINI_API_KEY=your-key-here`
3. Restart the app. A "🤖 AI-Generated Feedback" section appears below the roadmap.

The AI feedback section is completely hidden when no key is set — the app
functions identically without it.

## Responsible AI

- ✅ This tool is **guidance only** — it does not make hiring or rejection decisions
- ✅ Scores only **job-related skills**, education, projects, and experience
- ✅ **Never** scores gender, age, religion, nationality, photographs, marital status, or disability
- ✅ Uploaded resumes are processed **in memory** and are **not stored** on disk
- ✅ A missing keyword does not always mean missing ability — scores are estimates

## Known Limitations

- Skill detection relies on exact / near-exact string matching. Synonyms or
  unlisted skills won't be detected unless `skill_dictionary.csv` is extended.
- TF-IDF similarity is sensitive to resume length and wording. It is a
  secondary signal (30% weight), not a standalone judgment of fit.
- The job-role dataset is a curated starter set (8 roles) — intended to be
  extended for production use.
- PDF text extraction quality depends on the PDF generator; scanned PDFs
  (image-only) will return little or no text.
